ADC Trial Landscape

Methodology & source code

What this shows. Antibody-drug conjugate trials arranged by drug target (columns) against tissue group (rows), split by treatment intent. Each cell counts distinct trials; click one to list them.

Where the data comes from. Australian and New Zealand trials come from ARTiCANZ, a specialist-curated registry that annotates each trial with a drug-class ontology — that curated ontology is what makes a target × tissue view possible at all. Global trials come from the ClinicalTrials.gov API v2, filtered to confirmed ADCs by drug-name and payload-suffix matching ported from a published classifier.

Caveats worth knowing. ARTiCANZ cancer types come from a controlled vocabulary and map cleanly onto tissue groups. ClinicalTrials.gov conditions are free text resolved by regular expressions, so its tissue grouping is less reliable and its ADC detection can miss trials whose drug names aren't yet in the pattern list. Rows are hierarchical, so a trial can appear under more than one cancer type — column totals are the honest trial counts.

Rebuilt weekly, Saturday mornings AEST, after ARTiCANZ's Friday refresh. Everything is open: github.com/nedmcnamee/NedTrialLandscape — fork it if you want the same view for a different drug class, or open an issue if a trial looks miscategorised.
