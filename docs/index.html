ADC Trial Landscape

Methodology & source code

What this shows. Antibody-drug conjugate trials arranged by drug target (columns) against tissue group (rows), split by treatment intent. Each cell counts distinct trials; click one to list them.

Where the data comes from. Australian and New Zealand trials come from ARTiCANZ, a specialist-curated registry that annotates each trial with a drug-class ontolog. Global trials come from the ClinicalTrials.gov API v2, filtered to confirmed ADCs by drug-name and payload-suffix matching ported from a published classifier.

Reading the totals. Every number counts distinct trials. Margins deliberately do not sum to the grand total: a trial testing two targets, or enrolling several cancer types, legitimately occupies more than one cell. Column totals are the honest per-target counts.

Reading the colour. The scale is logarithmic and rescales to whatever is on screen. Always read the legend rather than comparing shades across different filter settings.

Caveats. ARTiCANZ cancer types come from a controlled vocabulary and map cleanly onto tissue groups. ClinicalTrials.gov conditions are free text resolved by regular expressions, so its tissue grouping is less reliable and its ADC detection can miss trials whose drug names aren't yet in the pattern list.

Rebuilt weekly, Saturday mornings AEST, after ARTiCANZ's Friday refresh. Everything is open: github.com/nedmcnamee/NedTrialLandscape — fork it if you want the same view for a different drug class, or open an issue if a trial looks miscategorised.
