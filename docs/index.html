ADC Trial Landscape

Methodology & source code

What this shows. Antibody-drug conjugate trials arranged by drug target against tissue group, split by treatment intent. Each cell counts distinct trials; click one to list them.

Where the data comes from. Australian and New Zealand trials come from ARTiCANZ, a specialist-curated registry that annotates each trial with a drug-class ontology — that curated ontology is what makes a target × tissue view possible at all. Global trials come from the ClinicalTrials.gov API v2, filtered to confirmed ADCs.

How the global set is assembled. ClinicalTrials.gov has no drug-class ontology, so ADCs are identified three ways: a list of known agents, generic INN payload suffixes (-tecan, -dotin, -tansine, excluding free camptothecins such as irinotecan), and drug names harvested weekly from ARTiCANZ itself. The Coverage tab reports how well that is working, measured against ARTiCANZ's curated calls.

Reading the totals. Every number counts distinct trials. Margins deliberately do not sum to the grand total: a trial testing two targets, or enrolling several cancer types, legitimately occupies more than one cell.

Reading the colour. The scale is logarithmic and rescales to whatever is on screen, because cell counts differ by an order of magnitude between the registries. Read the legend rather than comparing shades across different filter settings.

Rebuilt weekly, Saturday mornings AEST, after ARTiCANZ's Friday refresh. Everything is open: github.com/nedmcnamee/NedTrialLandscape — fork it if you want the same view for a different drug class, or open an issue if a trial looks miscategorised.

How complete is the global set?

ARTiCANZ curators identify ADCs from a drug-class ontology; we identify them from text patterns. Since 96% of ARTiCANZ ADC trials also carry an NCT number, ARTiCANZ acts as ground truth for our classifier. Anything it calls an ADC that we miss is listed below.
